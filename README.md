# Seguimiento de la bolsa
Script para hacer análisis y seguimiento de la bolsa de valores de Caracas en Python con la librería yfinance

Librería yfinance datos de Yahoo Finance

Librería no oficial que extrae datos de las API públicas de Yahoo Finance, no es una fuente institucional.

yfinance permite acceder a los estados financieros anuales y trimestrales directamente desde el objeto Ticker.
Muchas empresas venezolanas no reportan a Yahoo Finance
